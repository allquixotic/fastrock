# Contributing

Preserve the codex-gui foundation and the Rally acceptance ledger in
`docs/RALLY-INVENTORY.md`. All new UI must use native Slint controls. Keep inference
and agent execution in the installed external Codex app-server. Keep tokens in OS
credential vaults, I/O off the UI thread and tests on local fixtures.

All build profiles and entrypoints maximize compile speed. Optimized builds need
Sean's explicit authorization. Never launch GUI tests on Sean's Mac; use Windows.
Follow AGENTS.md and SPEC.md. Preserve Git history and unrelated changes.
Contributions use Apache-2.0; this is an independent community project.
