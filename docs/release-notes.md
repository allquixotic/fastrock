# Fastrock 0.5.5

- **Thinking effort** now offers a text field when an Amazon Bedrock profile has
  no selectable effort levels. Enter the level and select **Use effort**.
  **Save effort default** remembers the applied value for that provider and
  exact model ID.
- Named Bedrock Responses profiles send the typed value as entered. Built-in
  Bedrock uses Goose's effort values. Goose 1.59.2 still omits effort from
  Converse requests for GPT and opaque application inference profiles.

This release ships as a signed Windows x64 ZIP. Use **Quit** in the previous
version's tray menu before launching 0.5.5.
