# Fastrock 0.5.9

Selected text stays white in both light and dark mode. Read-only text uses a solid blue highlight in conversations, code blocks, tool output, the file viewer, and terminal. Editable fields use a solid teal highlight, including the composer, search boxes, and settings.

To upgrade, choose **Quit** in the previous version’s tray menu, extract the Windows x64 ZIP, and launch `fastrock.exe`. Fastrock uses your existing Goose configuration and credentials.
