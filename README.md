# Fastrock

Fastrock is a Rust/Slint desktop coding-agent app focused on first-class AWS
Bedrock and Bedrock Mantle support, low overhead, parallel conversations, and
external `rtk` command execution.

The product and engineering source of truth is [SPEC.md](SPEC.md). Agentic
development workflow rules live in [AGENTS.md](AGENTS.md).

Developer workflow details live in [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).
